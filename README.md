# CGH OS

CGH OS is a Debian 13 and GNOME based installation candidate for everyday work, development and home labs.

**0.5.1 RC1 is under validation. No accepted binary release has been published.** Source checks and physical-machine observations do not replace testing the exact ISO.

The current candidate uses recovered source commit `42911d312e49b17dff40666210c3e1188e0d4fc0`. Release preparation includes authenticated dependency inputs, a package inventory and SBOM, matching upstream source, license notices, signing and recovery documentation. Historical private diagnostic logs and screenshots are excluded from public source delivery.

Use only artifacts from a published release and verify their signatures and checksums. Do not install an unaccepted candidate on a drive containing important data. The installer can erase its selected drive.

Security reports: admin@crawfordgroupholdings.com. Include the version, reproduction steps and impact; omit credentials and private records. No support duration or response-time commitment is made for this candidate.

CGH code and bundled third-party software retain their individual licenses. A CGH license does not relicense Debian packages.
